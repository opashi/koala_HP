# 株式会社こあら コーポレートサイト

整体・ReBody（健康動画配信サブスク）・ノーコードLP開発ツールを紹介する、レスポンシブな静的サイトです。ビルドや外部ライブラリは不要です。

## 起動

Node.js 20以降で実行します。

```sh
npm start
```

ブラウザで `http://localhost:3000` を開きます。ポートは環境変数 `PORT` で変更できます。付属サーバーはローカル確認用です。本番公開時は静的ホスティングを利用し、HTML・CSS・ブラウザ用JS・imagesフォルダを配置してください。サーバー側ファイルやテストを公開する必要はありません。

## ページ

- トップ：`index.html`
- 会社概要：`company.html`
- 社長あいさつ：`message.html`（代表取締役社長：丸山 拓海）
- 事業内容・事業一覧：`services.html`
- こあらの強み：`strength.html`
- お知らせ：`news.html`
- 整体：`seitai.html`
- ReBody：`rebody.html`
- LP開発ツール：`lp-tool.html`
- お問い合わせ：`contact.html`
- 個人情報の取り扱い：`privacy.html`

共通レイアウト・本文・フォーム処理は `app.js`、スタイルは `styles.css` で管理しています。ロゴ・アイコンには支給画像を使用しています。写真はUnsplashから取得した画像をローカル配置しています。

ナビゲーションは `app.js` の `navigationItems` で管理しています。「会社概要」の下に会社概要・社長あいさつ、「事業内容」の下に事業一覧・整体・ReBody・LP開発ツールを配置しています。親項目は専用ページへのリンク、隣の矢印ボタンは下位ページの開閉です。PC・スマートフォンともにクリック／タップで開閉でき、Escapeキーやメニュー外のクリックで閉じられます。トップページの既存セクションとアンカーは維持しています。

お知らせページはトップと共通のサービス案内を表示します。未提供のニュース・公開日を仮作成していません。強みの説明はトップと共通データで管理しています。

## 公開前に必要な設定

- 会社概要の所在地を確定情報に更新。設立欄と沿革には2026年11月の設立予定を掲載しているため、設立後に両方の予定表記を更新。
- 社長あいさつの本文は既存の事業方針をもとに作成した文案です。公開前に代表者の確認・承認を受けてください。社長写真には支給の `images/maruyama.jpeg` を使用しています。全身写真よりも表情が見やすいため選定し、顔が切れないよう上寄せで配置しています。
- 各サービスの価格・店舗・契約条件・販売先等を確定情報に更新。
- お問い合わせ先と送信APIを用意し、サーバー側入力検証・迷惑送信対策・送信失敗時の通知を実装。
- お問い合わせ受付の開始に合わせ、個人情報保護方針を確定。

**現在のお問い合わせは下書きの確認・コピーのみです。送信機能はなく、入力内容をサーバーに送信・保存しません。** 架空の連絡先・料金・実績は掲載していません。

## アニメーション

全ページの見出し・カード・本文を、スクロールで初めて表示したときに一度だけフェードインします。表示前の要素をCSSで非表示にしないため、アニメーションAPIが利用できなくても内容は読めます。キーボードでフォーカスした要素の表示アニメーションは即座に解除します。

トップの葉・シンボルは4.8秒で終了する控えめな演出です。メニューの開閉、カード・ボタンへのホバーにも反応を加えています。端末の「視差効果を減らす」等（`prefers-reduced-motion: reduce`）では演出を停止し、設定の途中変更にも対応します。既存のレイアウト・ページ構成は変更していません。
